# FlashLaunch 闪启

Windows 原生轻量快速启动器。单文件绿色软件，无第三方运行时依赖，常驻内存约 10–25 MB。界面采用细腻渐变、圆角卡片、悬停反馈与系统材料效果，贴近当前 Fluent / 2026 桌面审美。

## 功能

- 全局热键唤醒（默认 `Alt+Space`，冲突时自动尝试 `Ctrl+Alt+Space` / `Ctrl+Shift+Space` / `Alt+Shift+Space`）
- **计算器**：输入算式（如 `(1+2)*3`、`2^10`、`10/4`）即时显示结果，`Enter` 复制到剪贴板
- 中文、全拼、拼音首字母、英文子串、多关键词组合搜索，按相关度 + 使用频率排序
- **复制路径**：`Ctrl+Shift+C` 复制选中项完整路径
- **主题皮肤**：深色 / 浅色 / 跟随系统 / 云母 Mica / 亚克力 / 玻璃模糊六套，设置中用自绘下拉菜单选择并即时预览；系统材料效果按 Windows 版本自动降级
- **多显示器**：唤醒窗口可跟随鼠标所在屏幕居中，也可固定主屏
- 自动索引：开始菜单、桌面、PATH 可执行文件、注册表 App Paths、UWP/Microsoft Store 应用、`.url` 网址快捷方式
- 后台线程索引，界面即时响应；**未输入关键词时不显示结果列表**
- 独立深色设置窗口，无需手动编辑配置文件
- 图标按需加载，缓存上限 400 个
- 使用记录排序（最近使用优先）
- 托盘菜单：显示/隐藏、重新索引、开机自启、设置、退出
- 单实例，重复启动自动唤起已有窗口

| 按键 | 功能 |

| `Alt+Space` | 显示 / 隐藏（可配置） |
| `↑` `↓` | 选择结果 |

| 点击标题栏齿轮 | 打开设置 |

## 设置

点击标题栏右侧齿轮图标，或右键托盘图标选择「设置」，打开独立深色设置窗口。窗口采用侧栏四页布局：

- **常规**：唤醒快捷键——**点击快捷键字段后直接按下组合键自动识别，不支持手动输入**；支持 `Ctrl` / `Alt` / `Shift` / `Win` 与字母、数字、`F1–F12`、`Space`、`Enter`、`Tab`，`Esc` 取消捕获；冲突时自动尝试备用组合；点击「禁用」可关闭全局热键（托盘/齿轮入口仍可打开窗口）；开机自启；**界面主题**（深色 / 浅色 / 跟随系统 / 云母 / 亚克力 / 玻璃，下拉选择后立即预览，保存后永久生效，取消回滚）；**跟随鼠标定位**（开=在多屏间跟随光标弹出，关=固定主屏居中）
- **搜索**：结果数量 3–16 条（默认 8）、拼音首字母胶囊显示
- **目录**：附加检索目录（每行一个），可用「+ 添加目录」浏览；「重建索引」使改动马上生效
- **关于**：版本与实现说明
- **保存 / 取消**：底部操作栏，保存后立即生效；`Esc` 关闭窗口

设置由程序自动写入同目录的 `FlashLaunch.ini` / `FlashLaunch.history` 作为内部存储，**无需也不建议手动编辑**；界面上不再提供“打开配置文件”入口。

## 编译

需要 mingw-w64：

```sh
./build.sh
```

拼音表由 `tools/gen_pinyin.py` 生成（依赖 `pypinyin`），图标由 `tools/gen_icon.py` 生成（依赖 `Pillow`）。生成物已提交，正常编译无需重新生成。

## 设计与资源占用

- 纯 Win32 + GDI，无 Qt/Electron/WPF，无 .NET/VC++ 运行时依赖
- 静态链接 libgcc/libstdc++，`-Os -fno-exceptions -fno-rtti --gc-sections`
- 编译产物约 200–400 KB（含 20,924 汉字拼音表）
- 空闲时无轮询、无定时器；索引完成后仅消息循环等待
- 图标按需加载 + LRU 淘汰；列表使用内存 DC 双缓冲绘制
- 常驻内存：典型 10–25 MB，远低于 100 MB 目标

## 已知限制

- 仅支持 BMP 内 CJK 汉字（U+4E00–U+9FFF），覆盖日常使用
- 多音字按常用读音匹配
- UWP 应用以 `shell:AppsFolder\<PackageFamilyName>!App` 方式启动
